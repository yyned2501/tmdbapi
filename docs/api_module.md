# API 服务与控制器路由说明文档

`api` 模块是本项目的外部通信边界和控制层，采用 FastAPI 框架，提供了标准的 JSON 交互接口，并且完全逆向兼容了 TMDB 官方 HTTP 协议的第三版路由架构（`/3` 端点）。

---

## 1. 模块职责与应用生命周期 (`api.main`)

### ① 应用启动与生命周期流程 (`lifespan`)
*   **探活与建表**: 应用启动时调用 `core.database.ensure_database_ready()` 执行探活。探活成功后，自动在底层数据库中执行 `create_all` 映射生成 `media` 和 `api_cache` 实体表结构。
*   **自愈降级特性**: 若探活失败且未配置 `startup_check_required` 强制校验，应用将进入**降级就绪状态**启动并继续提供代理服务，当数据库恢复后底层可自愈重连。
*   **后台主动缓存清理任务 (`cache_cleanup_loop`)**: 
    - 启动时通过 `asyncio.create_task` 挂载一个后台无限循环协程任务。
    - 在运行 **1分钟后** 开始执行首次清理（以避开高负载的启动期）。
    - 随后**每 6 小时**自动向数据库发出 `delete` 指令，一次性回收和物理销毁所有达到 `expires_at` 绝对寿命截止时间的 APICache 记录，保持存储轻量和整洁。
*   **优雅关闭**: 应用关闭（Shutdown）时，自动向后台垃圾清理协程发送 `.cancel()` 中断信号，并显式调用 `tmdb_client.close()` 安全释放、销毁底层 httpx 异步网络客户端连接池。

## 2. 元数据本地检索路由 (`api.v1.media`)

### 本地服务路由接口

#### ① `GET /api/v1/media/search`
*   **用途**: 通过指定刮削器进行电影/电视的高级搜索，并将返回结果自动持久化、同步和更新到本地 `media` 表。
*   **查询参数**:
    - `query` (`str`, 必填): 搜索关键字词。
    - `scraper` (`str`, 选填, 默认 `"tmdb"`): 执行刮削的 scraper 键（如 `"tmdb"`, `"mdc"`）。
*   **返回值**:
    - `List[MediaRead]`: 经过 Pydantic 反序列化、映射完成的本地 `Media` 记录列表。

#### ② `GET /api/v1/media/{media_id}`
*   **用途**: 获取本地库存储的特定单条媒体元数据详情。
*   **路径参数**:
    - `media_id` (`int`, 必填): 数据库自增本地主键。
*   **返回值**:
    - `MediaRead`: 本地存储的 `Media` 字段信息。若未查到，抛出 `404 Not Found` 错误。

## 3. 兼容官方 TMDB API 代理路由 (`api.v1.tmdb_proxy`)

### 代理与更新自愈逻辑 (`_proxy_request`)
本项目实现了无缝替换原版 TMDB 地址（充当 TMDB 代理服务）的控制接口。所有兼容端点在接收到请求时均使用 `_proxy_request` 核心调度器处理：
1.  **查询缓存**: 传入请求路径和参数包计算 SHA-256 Key。调用 `cache_service.get` 进行缓存查询。
2.  **新鲜直接返回**: 若命中缓存且未超出优先缓存期（`prefer_cache_hours`），则不向 TMDB 发送任何网络请求，直接将缓存的数据秒级返回给请求端（响应耗时 0-5ms）。
3.  **过期优先直连**: 若未命中缓存或已越过优先缓存期（过时缓存）：
    - 代理将异步尝试向官方 TMDB 发起直连网络请求，拉取最新内容。
    - 若网络直连成功，自动执行 `_save_cache` 复写并刷新缓存，并在后台异步触发 `_background_sync` 提取刮削格式合并并批量写入/更新 `media` 库。
4.  **降级回退机制**: 若网络直连官方 TMDB 发生任何意外失败（如断网、API 额度超限），且**当前存在过时的本地缓存**，代理会自动拦截网络异常并降级回退：**直接使用本地过期的缓存数据返回给客户端，保障上游系统（如 Plex, Emby）稳定读取数据不报 500**。

### 注册的兼容路由端点

#### ① `GET /3/search/movie`
*   **用途**: 逆向兼容官方 TMDB 的电影搜索。
*   **查询参数**: 同官方 TMDB，主要为 `query`。
*   **返回值**: 符合官方 `TMDBSearchResponse` 的 JSON 报文。

#### ② `GET /3/search/tv`
*   **用途**: 逆向兼容官方 TMDB 的剧集搜索。
*   **查询参数**: 同官方 TMDB，主要为 `query`。
*   **返回值**: 官方 TV 搜索格式 JSON 报文。

#### ③ `GET /3/movie/{movie_id}`
*   **用途**: 逆向兼容官方电影详情获取。
*   **路径参数**: `movie_id` 官方电影 ID。
*   **返回值**: 官方电影详情格式 JSON。

#### ④ `GET /3/tv/{tv_id}`
*   **用途**: 逆向兼容官方剧集详情获取。
*   **路径参数**: `tv_id` 官方剧集 ID。
*   **返回值**: 官方剧集详情格式 JSON。

#### ⑤ `GET /3/tv/{tv_id}/season/{season_number}`
*   **用途**: 逆向兼容官方电视季度详情获取。
*   **路径参数**: 剧集 ID 及季度编号。
*   **返回值**: 官方剧集季度格式 JSON。

#### ⑥ `GET /3/{path:path}`
*   **用途**: 兜底转发端点，代理并支持以上未显式列出的所有其他官方 API 请求。
